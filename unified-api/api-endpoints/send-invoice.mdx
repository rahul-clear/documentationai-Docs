---
title: Send e-Invoice
description: 'Submit e-invoices for validation and routing'
---

**Method:** `POST`

The Send e-Invoice API submits e-invoices for validation and routing to relevant parties based on the country model (CTC, 4C, or 5C). The API first validates the invoice, then routes it to:

- The Receiver (4C/5C models)
- The Government, for reporting (4C/5C models)
- The Government, for approval (CTC models)

Returns HTTP 200 on successful validation (4C/5C models) or approval (CTC models).

<Callout kind="info" collapsed="false">
  The API accepts a `Documents` array to submit multiple invoices in a single call. Each invoice's JSON payload is Base64-encoded and placed in `Documents[].DocumentData`. Schema requirements vary by country, building upon the Base Schema framework.
</Callout>

## Endpoint

| Environment | URL |
|---|---|
| Production | `POST https://api.mea.cleartax.com/einvoice/v1/documents/send?einvoice-type=SALES` |
| Sandbox | `POST https://api-sandbox.mea.cleartax.com/einvoice/v1/documents/send?einvoice-type=SALES` |

## Request Headers

| Header | Required | Description |
|---|---|---|
| `x-ClearTax-auth-token` | Mandatory | User auth token. |
| `x-clear-[nodeId]` | Mandatory | Refer to Node ID for details. |
| `x-clear-branch` | Optional | Branch (store) name mapped to a VAT/VATIN of the entity. |
| `x-request-id` | Optional | Unique ID per request; used as a trace ID. Auto-populated if omitted. |
| `x-clear-country-code` | Mandatory | Refer to Country Code for details. |
| `Content-Type` | Mandatory | `application/json` |

## Request Query Parameters

| Parameter | Data Type | Possible Values | Description |
|---|---|---|---|
| `einvoice-type` | ENUM | `SALES` / `PURCHASE` | Designates invoice classification: SALES for Billed and PURCHASE for Self-Billed Invoices. |

## Request Body

### Root Level

| Field | Type | Required | Description |
|---|---|---|---|
| `Documents` | Array | Mandatory | List of invoice documents. Min: 1, Max: 10. |

### Documents Array Items

| Field | Type | Required | Description |
|---|---|---|---|
| `Documents[].DocumentData` | String | Mandatory | Base64-encoded JSON of the e-Invoice object. |
| `Documents[].DocumentFormat` | Enum | Mandatory | Format of the document data. Only `JSON` is supported. |
| `Documents[].CustomFields` | Object | Optional | Key-value pairs for custom fields in PDF templates or reports. |

## Response Schema

### Document Response Object

| Field | Type | Description |
|---|---|---|
| `Success` | Boolean | Indicates whether the overall request was successfully processed. |
| `DocumentResponses` | Array | List of response objects, one per document in the request. |
| `DocumentResponses[].DocumentId` | String | Unique document ID generated by ClearTax. Use in the Status Check API. |
| `DocumentResponses[].UniqueId` | String | Unique ID to distinctly identify the document. |
| `DocumentResponses[].Success` | Boolean | Whether this specific document was successfully processed. |
| `DocumentResponses[].ErrorDetails` | Array | Optional. List of error objects. |
| `DocumentResponses[].WarningDetails` | Array | Optional. List of warning objects. |

### Error Detail Object

| Field | Type | Description |
|---|---|---|
| `ErrorCode` | String | Code identifying the error. |
| `ErrorMessage` | String | Human-readable error message. |
| `ErrorSource` | String | Source of the error. Value: `CLEARTAX`. |
| `Path` | String | For field-level validation errors, points to the offending field path. |

### Warning Detail Object

| Field | Type | Description |
|---|---|---|
| `Code` | String | Code identifying the warning. |
| `Message` | String | Human-readable warning message. |

## API Constraints

- **Authentication:** Requires a valid auth token. Returns `401` if missing or expired. Returns `403` if the user lacks Admin role for the entity.
- **Batch Size:** The API accepts between 1 and 10 documents per single request.
- **Rate Limiting:** Up to 10,000 requests per minute.
- **Payload Size:** Individual requests are limited to a maximum of 100 MB.

## Sample Request & Response

**Headers:**

```
x-cleartax-auth-token: <Auth token>
x-clear-country-code:  AE
x-clear-trn:           <TRN>
Content-Type:          application/json
```

**Request Body:**

```json
{
  "Documents": [{
    "DocumentData": "<base64-encoded eInvoice JSON>",
    "DocumentFormat": "JSON",
    "CustomFields": { "Internal Number": "INV-0000001" }
  }],
  "schema": "CLEAR_UNIFIED_SCHEMA"
}
```

**HTTP 200 - Success:**

```json
{
  "ErrorDetails": null,
  "Success": true,
  "DocumentResponses": [
    {
      "DocumentId": "<Clear's Unique Document ID>",
      "Success": true,
      "UniqueId": "<Document's Unique Id>",
      "ErrorDetails": [],
      "WarningDetails": null,
      "CustomFields": {}
    }
  ]
}
```

**HTTP 200 - Document-Level Error:**

```json
{
  "ErrorDetails": null,
  "Success": true,
  "DocumentResponses": [
    {
      "DocumentId": null,
      "Success": false,
      "UniqueId": "<Document's Unique Id>",
      "ErrorDetails": [
        {
          "ErrorCode": "ERR-10001",
          "ErrorMessage": "Supplier TRN is not matching the TRN present in the account",
          "ErrorSource": "CLEARTAX"
        }
      ],
      "WarningDetails": []
    }
  ]
}
```

**HTTP 200 - Duplicate Submission Warning:**

```json
{
  "ErrorDetails": null,
  "Success": true,
  "DocumentResponses": [
    {
      "DocumentId": "<Clear's Unique Document ID>",
      "Success": true,
      "UniqueId": "<Document's Unique Id>",
      "ErrorDetails": [],
      "WarningDetails": [
        {
          "Code": "DUP-202",
          "Message": "Invoice is already submitted, we are returning the response from the previously submitted Invoice"
        }
      ],
      "CustomFields": {}
    }
  ]
}
```
