---
title: Send via Email
description: 'Email a previously submitted e-invoice PDF to recipients'
---

**Method:** `POST`

This API emails a previously submitted e-invoice's PDF to recipients, utilizing a ClearTax print template for the attachment and an email template for the message itself.

## Endpoint

| Environment | URL |
|---|---|
| Production | `POST https://api.mea.cleartax.com/einvoice/v1/emails/send` |
| Sandbox | `POST https://api-sandbox.mea.cleartax.com/einvoice/v1/emails/send` |

## Request Headers

| Header | Required | Description |
|---|---|---|
| `x-ClearTax-auth-token` | Mandatory | User auth token. |
| `x-clear-[nodeId]` | Mandatory | Refer to Node ID for details. |
| `x-clear-branch` | Optional | Branch (store) name mapped to a VAT/VATIN of the entity. |
| `x-request-id` | Optional | Unique ID per request; used as a trace ID. Auto-populated if omitted. |
| `x-clear-country-code` | Mandatory | Refer to Country Code for details. |
| `Content-Type` | Mandatory | `application/json` |

## Request Body

### Root Level

| Field | Type | Required | Description |
|---|---|---|---|
| `Attachments` | Object | Mandatory | Describes which document(s) to email. |
| `PreviewDetails` | Object | Mandatory | Email content and recipients. |

### Attachments Object

| Field | Type | Required | Description |
|---|---|---|---|
| `DocumentDetails` | Array | Mandatory | List of Document Details objects for e-invoice PDF attachment. |
| `DocumentType` | Enum | Mandatory | Type of document to print; value: `EINVOICE`. |
| `PrintTemplateId` | String | Optional | Print template ID; defaults to `2` (Standard Invoice Template). |

### Attachments.DocumentDetails Array Items

| Field | Type | Required | Description |
|---|---|---|---|
| `DocumentNumber` | String | Mandatory | Document number. |
| `DocumentDate` | String | Mandatory | Format: `YYYY-MM-DD`. |
| `DocumentType` | String | Mandatory | Document type (e.g., `INV`). |
| `TaxPayerIdentifier` | String | Mandatory | Must match `x-clear-[nodeId]` header value. |

### PreviewDetails Object

| Field | Type | Required | Description |
|---|---|---|---|
| `Template` | Object | Mandatory | Email Template object. |
| `CounterParties` | Array | Mandatory | List of Counterparty Details objects. |

### PreviewDetails.Template Object

| Field | Type | Required | Description |
|---|---|---|---|
| `Type` | Enum | Mandatory | `EINVOICE_GENERATED` or `EINVOICE_PAYMENT_REMINDER`. |

### PreviewDetails.CounterParties Array Items

| Field | Type | Required | Description |
|---|---|---|---|
| `Contacts` | Array | Mandatory | List of Contact Details objects (email recipients). |

### PreviewDetails.CounterParties[].Contacts Array Items

| Field | Type | Required | Description |
|---|---|---|---|
| `Email` | String | Mandatory | Recipient email address. |
| `EmailRecipientType` | Enum | Mandatory | `TO`, `CC`, `BCC`, or `REPLY_TO`. |

## Response Schema

### Top-Level Response

| Field | Type | Description |
|---|---|---|
| `Success` | Boolean | Whether the request was processed successfully. |

<Callout kind="info" collapsed="false">
  This endpoint returns confirmation of successful processing rather than the email artifact itself.
</Callout>

### Error Detail Object

| Field | Type | Description |
|---|---|---|
| `ErrorCode` | String | Code identifying the error. |
| `ErrorMessage` | String | Human-readable error message. |
| `ErrorSource` | String | Source of the error. Possible value: `CLEARTAX`. |
| `Path` | String | For field-level validation errors, points to the offending field path. |

## API Constraints

- **Authentication:** Requires a valid auth token. Returns `401` if missing or invalid. Returns `403` if the user isn't authorized.
- **Document Status:** All referenced documents must already exist in ClearTax and be in `Valid`, `Cancelled`, or `Invalid` state.
- **Print Template:** `PrintTemplateId`, if provided, must exist in ClearTax.
- **Rate Limiting:** 10K requests per min.

## Sample Request & Response

**Headers:**

```
x-cleartax-auth-token: <Auth token>
x-clear-country-code:  AE
x-clear-trn:           <TRN>
Content-Type:          application/json
```

**Request Body:**

```json
{
  "Attachments": {
    "DocumentDetails": [
      {
        "DocumentNumber": "2056",
        "DocumentDate": "2022-07-20",
        "DocumentType": "INV",
        "TaxPayerIdentifier": "300492946900003"
      }
    ],
    "DocumentType": "EINVOICE",
    "PrintTemplateId": "40"
  },
  "PreviewDetails": {
    "Template": {
      "Type": "EINVOICE_GENERATED"
    },
    "CounterParties": [
      {
        "Contacts": [
          {
            "Email": "abc@company.com",
            "EmailRecipientType": "TO"
          }
        ]
      }
    ]
  }
}
```

**HTTP 200 - Success:**

```json
{
  "Success": "true"
}
```

**HTTP 200 - Validation Error:**

```json
{
  "ErrorDetails": [
    {
      "ErrorCode": "EINV-EM-002",
      "ErrorMessage": "Document Number cannot be empty",
      "ErrorSource": "CLEARTAX",
      "Path": "Attachments.DocumentDetails[0].DocumentNumber"
    }
  ]
}
```
