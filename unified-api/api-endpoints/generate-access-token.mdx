---
title: Generate Access Token
description: 'Exchange your client secret for a short-lived access token'
---

**Method:** `GET`

This endpoint allows API clients to exchange their client secret for a short-lived access token. The token is then used as the `x-ClearTax-auth-token` header value when making subsequent requests to other Unified e-Invoicing APIs.

## Endpoint

| Environment | URL |
|---|---|
| Production | `GET https://api.mea.cleartax.com/integration/v1/authz/token` |
| Sandbox | `GET https://api-sandbox.mea.cleartax.com/integration/v1/authz/token` |

## Request Headers

| Header | Required | Description |
|---|---|---|
| `x-clear-client-secret` | Mandatory | API client secret generated from the ClearTax UI. |

No request body is required for this API call.

## Response Schema

### Main Response Fields

| Field | Type | Description |
|---|---|---|
| `access_token` | String | Access token generated by ClearTax. Max length 256. Not returned if there are errors. |
| `valid_till` | String | ISO 8601 timestamp (UTC) indicating expiration, formatted as `YYYY-MM-DDTHH:MM:SS+00:00`. Returns `null` if configured never to expire. |
| `errors` | Array | Array of Error Detail objects. Not returned if there are no errors. |

### Error Detail Object

| Field | Type | Description |
|---|---|---|
| `error_code` | String | Code corresponding to the failed validation rule or precondition. |
| `error_message` | String | Detailed explanation of what caused the error. |
| `error_source` | String | Origin identifier; always `CLEAR` for this service. |
| `error_id` | String | Unique reference ID for unhandled exceptions; supply when contacting support. |

<Callout kind="info" collapsed="false">
  This endpoint uses `snake_case` field names and an `errors` array structure, which differs from the PascalCase/`ErrorDetails` convention used in other API sections.
</Callout>

## API Constraints

- **Authentication:** Requires a valid, active client secret. Returns `401` if missing, empty, invalid, incomplete, or if the API client has been deleted.
- **IP Allowlisting:** If the request originates from an IP outside the range configured on the API client, the API returns `401`.
- **Rate Limiting:** 10K requests per min.

## Sample Request & Response

**Headers:**

```
x-clear-client-secret: <client secret>
```

**HTTP 200 - Success:**

```json
{
  "valid_till": "2025-02-20T10:04:47+00:00",
  "access_token": "1.c3da9800-f36e-46fb-bdf0-99f10b7f1afd_80b0f6c95755668ea6728ce441e82a5f6f"
}
```

**HTTP 401 - Missing or empty client secret:**

```json
{
  "errors": [
    {
      "error_code": "CLI-SEC-001",
      "error_message": "Client secret header is missing or value is empty.",
      "error_source": "CLEAR",
      "error_id": null
    }
  ]
}
```

**HTTP 401 - Invalid or inactive client secret:**

```json
{
  "errors": [
    {
      "error_code": "CLI-SEC-002",
      "error_message": "Invalid or inactive client secret.",
      "error_source": "CLEAR",
      "error_id": null
    }
  ]
}
```
