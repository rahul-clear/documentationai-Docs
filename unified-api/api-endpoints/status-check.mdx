---
title: Status Check
description: 'Check Document Status and Government Reporting Status'
---

**Method:** `GET`

The Status Check API is used to check both the Document Status and the Government Reporting Status.

<Callout kind="info" collapsed="false">
  The `DocumentId` obtained from the Send e-Invoice response serves as a path parameter for this endpoint.
</Callout>

## Endpoint

| Environment | URL |
|---|---|
| Production | `GET https://api.mea.cleartax.com/einvoice/v1/documents/[<documentId>]/status?[einvoice-type=SALES]` |
| Sandbox | `GET https://api-sandbox.mea.cleartax.com/einvoice/v1/documents/[<documentId>]/status?[einvoice-type=SALES]` |

## Request Headers

| Header | Required | Description |
|---|---|---|
| `x-ClearTax-auth-token` | Mandatory | User auth token. |
| `x-clear-[nodeId]` | Mandatory | Refer to Node ID for details. |
| `x-clear-branch` | Optional | Branch (store) name mapped to a VAT/VATIN of the entity. |
| `x-request-id` | Optional | Unique ID per request; used as a trace ID. Auto-populated if omitted. |
| `x-clear-country-code` | Mandatory | Refer to Country Code for details. |
| `Content-Type` | Mandatory | `application/json` |

## Request Path Parameters

| Parameter | Data Type | Possible Values | Description |
|---|---|---|---|
| `DocumentId` | String | DocumentId generated by Clear | Unique ID for the Invoice received in the Send e-Invoice API response. |

## Request Query Parameters

| Parameter | Data Type | Possible Values | Description |
|---|---|---|---|
| `einvoice-type` | ENUM | `SALES` / `PURCHASE` | SALES for Sales Invoices and PURCHASE for Purchase Invoices. |

## Response Schema

### Primary Response Fields

| Field | Type | Description |
|---|---|---|
| `Success` | Boolean | Whether the status check request was processed successfully. |
| `DocumentId` | String | The ClearTax document ID. |
| `Status` | Enum | References document status values documentation. |
| `ErrorDetails` | Array | Optional. List of error objects if processing failed. |
| `ReportingDetails` | Array | Optional, 5C models. Government reporting status per action. |

### ReportingDetails Array Object

| Field | Type | Description |
|---|---|---|
| `TransactionId` | String | Identifier for the reporting transaction, if assigned. |
| `Action` | String | The reporting action, e.g. `TDD_REPORTING`. |
| `ActionType` | String | Category of the action, e.g. `TAX_REPORTING`. |
| `Status` | Enum | References government reporting status values. |
| `ReceivedAt` | String | Timestamp the action was received by the tax authority, if available. |
| `StatusReasons` | Array | Reasons for the status, if the tax authority provided any. |

### ErrorDetail Object

| Field | Type | Description |
|---|---|---|
| `ErrorCode` | String | Code identifying the error. |
| `ErrorMessage` | String | Human-readable error message. |
| `ErrorSource` | String | Source of the error. Value: `CLEARTAX`. |
| `Path` | String | For field-level validation errors, points to the offending field path. |

## API Constraints

- **Authentication:** Requires a valid auth token. Returns `401` if missing or expired. Returns `403` if the user lacks Admin role.
- **Rate Limiting:** 10K requests per min.
