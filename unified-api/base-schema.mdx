---
title: Base Schema
description: 'The common EN16931-based schema shared across all countries on the Unified API'
---

The API accepts a single JSON payload organized into 28 business term groups (BGs). This model is based on EN16931, the European standard for electronic invoicing semantics, using the Peppol BIS Billing 3.0 framework as the underlying structure.

Each country's schema builds on this common core by adding or removing fields as needed - so your core integration stays unchanged as you expand to new markets. The base schema provides a standardized starting point that individual nations customize through delta schemas — modifications that add or remove particular fields without disrupting the core structure. See each country's Delta Schema page for its specific variations.

## BG-1 Invoice Information

|---|---|---|---|---|---|
| Invoice number | `id` | Identifier | BT-001 | A unique identifier for the invoice, assigned by the seller. | Mandatory |
| Invoice issue date | `issueDate` | Date | BT-002 | The date on which the invoice was issued. | Mandatory |
| Invoice type code | `invoiceTypeCode.value` | Code | BT-003 | A code specifying the functional type of the invoice (e.g. 380 = commercial invoice, 381 = credit note). | Mandatory |
| Invoice currency code | `documentCurrencyCode` | Code | BT-005 | The currency in which all invoice amounts are expressed, using ISO 4217 three-letter codes. | Mandatory |
| VAT accounting currency code | `taxCurrencyCode` | Code | BT-006 | The currency used for VAT accounting and reporting when different from the invoice currency. | Conditional Mandatory |
| Value added tax point date | `taxPointDate` | Date | BT-007 | The date when VAT becomes accountable for the seller and the buyer. | Optional |
| Payment due date | `dueDate` | Date | BT-009 | The date by which the buyer should pay. | Conditional Mandatory |
| Buyer reference | `buyerReference` | Text | BT-010 | An identifier assigned by the buyer for internal routing purposes (e.g. cost centre, project code). | Conditional Mandatory |
| Project reference | `projectReference.id` | Identifier | BT-011 | An identifier for the project to which the invoice relates. | Optional |
| Contract reference | `contractDocumentReference.id.value` | Identifier | BT-012 | An identifier for the contract to which the invoice relates. | Optional |
