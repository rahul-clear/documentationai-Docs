ClearTax's Unified e-Invoicing API lets you integrate once against a single consolidated schema and activate multiple countries without restructuring your integration.

**Coverage:** Belgium 🇧🇪, Malaysia 🇲🇾, and the UAE 🇦🇪 today, with more markets being added over time.

**What's in the schema:** invoice headers, supplier/buyer details, tax calculations, line items, and payment terms - 13 parent objects in total, shared across all supported countries.

**What the docs cover:**

- **API Reference** - base schema, endpoints, headers, authentication, and status codes for invoice submission (POST) and status tracking (GET)
- **Country Guides** - market-specific requirements, field mappings, and sample payloads for each jurisdiction (Belgium/Malaysia/UAE run on Peppol PINT-EU, LHDN MyInvois, and Peppol PINT-AE respectively)
- **Resources** - code lists, validation rules, and field mappings connecting the ClearTax JSON schema to each region's local standard
