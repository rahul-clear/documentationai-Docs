This page lists, business-group by business-group, how the UAE (PINT-AE) invoice schema differs from the ClearTax base schema — fields added, removed, or changed in mandatory status.

<Callout kind="warning" collapsed="false">
  Some UAE/PINT-AE-specific fields on the source site did not carry a written description — those are marked below as auto-derived from the field name rather than sourced text. Verify these against the PINT-AE spec before publishing.
</Callout>

## BG-1: Invoice Information

**New Mandatory Fields**
- **Uuid** — Unique identifier for UAE/PINT-AE
- **Profile execution id** — Identifier for profile execution
- **Source currency code** — Required currency reference
- **Target currency code** — Required currency reference

**New Optional Fields**
- **Invoice issue time** — Time component added to issue date (format: `14:30:00`)
- **Document description** — For contract document references
- **Value** (Statement document reference) — Identifier field
- **Terms payment instructions ID** — Links to applicable payment instructions
- **Terms installment due date** — Due date for installment payments

**New Conditional Mandatory Fields**
- **Response code** — Required when invoice type is a credit note
- **Calculation rate** — Required when invoice currency differs from AED (max 6 decimals)
- **Value** (Buyer ID) — Required for free trade zone transactions
- **Value** (Seller ID) — Required for disclosed agent billing scenarios

**Modified Fields**
- **Buyer reference** — Conditional Mandatory → Optional
- **Payment terms** — Conditional Mandatory → Optional
- **Invoiced Object Identifier Document Type Code** — Optional → Mandatory (value: `130`)

## BG-20: Document Level Allowances/Charges

**Modified**
- Document Level Allowance Base Amount currency code: Optional → Mandatory
- Document level allowance/charge amount: Mandatory → Conditional Mandatory
- Document level allowance/charge VAT category code: → Conditional Mandatory

**New Conditional Mandatory**
- Document level allowance or charge VAT exemption reason text
- Document level allowance or charge VAT exemption reason code (e.g. `VATEX-EU-O`)

**Conditional rules**
- Base amount and percentage must either both exist or neither exist.
- When base amount and percentage are provided, the allowance/charge amount must equal `base amount × percentage ÷ 100`.
- For exempt VAT categories, the exemption reason code becomes mandatory.

**Validations**
- `ibr-115-ae` — Document level allowance tax category code cannot be "Standard rate additional VAT".
- `ibr-122-ae` — Certain invoice types restrict VAT category codes to Exempt/Not subject/Zero-rated only.
- Exemption reason text/code limited to a maximum of one occurrence each.
