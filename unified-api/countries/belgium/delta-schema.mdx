Belgium runs on Peppol BIS Billing 3.0. This page lists only the fields whose cardinality, type, or rules differ from the [Base Schema](/unified-api/base-schema).

## BG-1 Invoice Information

| Field | JSON Path | Type | BT ID | Description | Sample | Delta Change |
|---|---|---|---|---|---|---|
| Buyer reference | `buyerReference` | Alphanumeric | IBT-010 | An identifier assigned by the Buyer used for internal routing purposes | `abs1234` | Conditional Mandatory → Optional |
| Purchase order reference | `orderReference.id` | String | IBT-013 | Reference number of the Purchase Order | `98776` | Conditional Mandatory → Mandatory |
| Currency Exchange Rate | `#n.a` | — | NA | Used when invoice currency and tax currency differ | `0.87` | New Conditional Mandatory |
| TAX point date code | `invoicePeriod.descriptionCode` | String | IBT-008 | The code of the date when the TAX becomes accountable for Seller and Buyer | `35.0` | New Optional |
| Invoiced Object Identifier Scheme Identifier | `additionalDocumentReference.id.schemeID` | Enum | IBT-018-1 | Scheme identifier from UNTDID 1153 code list | `CT` | Optional → Conditional Mandatory |

<Callout kind="info" collapsed="false">
  Currency exchange rate becomes mandatory when invoice currency differs from EUR, to allow correct tax calculation and proper conversion into the standard reporting currency.
</Callout>
