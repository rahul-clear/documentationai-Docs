---
title: PDF Merge
description: Add-on to merge supporting documents received via Peppol with the generated invoice PDF
---
✓ As part of AP inbox routing, Taxpayers can request for merging all additional supporting documents received via Peppol network from Supplier with the ClearTax generated eInvoice PDF.

✓ Output will be a single PDF attached to the Email.

✓ A maximum of 4 additional documents with collective size of up to 24mb are supported.

✓ Enablement and disablement of the feature can be requested via CSM.
