## RBAC

Role-based access control lets your workspace administrator assign users to roles with different permissions, controlling who can view, create, approve, or act on invoices within your workspace, in line with your internal segregation-of-duties requirements.

| Roles | Description |
| --- | --- |
| E-Invoice User | This role provides the user access to all actions for both sales & purchase documents within e-invoicing i.e Upload, Generate, View, Cancel, Request for rejection, Download, Print, Email |
| Sales E-Invoice User | This role provides the user access to all actions for only sales documents within e-invoicing i.e Upload, Generate, View, Cancel, Download, Print, Email |
| Purchase E-Invoice User | This role provides the user access to all actions for only purchase documents within e-invoicing i.e Upload, Generate, View, Cancel, Self-billing, Request for rejection, Download, Print, Email |
| View Only User | This role provides access to only view & download both sales & purchase documents. With this role, the user won't be able to take any action or upload any new data in e-Invoicing. |
| Sales View Only User | This role provides access to only view & download only sales documents. With this role, the user won't be able to take any action or upload any new data in e-Invoicing. |
| Purchase View Only User | This role provides access to only view & download only purchase documents. With this role, the user won't be able to take any action or upload any new data in e-Invoicing. |
| Guest User | Guest User |
| Guest View Only | Guest View Only |

## Audit Trail

- ClearTax maintains an invoice-specific audit trail recording every event in an invoice's lifecycle, giving a complete chronological record for compliance, review, and regulatory audits.
- Events captured include system events, government reporting events, MLS/status changes received from the counterparty's Access Point, and your team's own actions on the invoice.
- Each entry includes a timestamp, a status badge indicating the outcome, and, where applicable, the user who triggered the action.
- Your team can view the complete chronological event log for any invoice directly on the ClearTax platform.
- **Audit Events API (additional SKU)** - programmatic access to the same audit data - a chronological event list per invoice, filterable by event source (system, Access Point, government) and time range - for integration with your compliance monitoring or internal audit systems.
