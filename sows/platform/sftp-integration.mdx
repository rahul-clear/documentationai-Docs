---
title: SFTP Integration - With Excel/XML Format Transformation
description: >-
  Ingest non-standard invoice formats via SFTP and process through standard
  flows
---
✓ ClearTax accepts invoice data from your systems via SFTP (Excel or XML), transforms it into the mandate-compliant format, and processes it through the standard e-invoicing flows. Response and output files (status responses, error reports, delivery confirmations) are returned on your SFTP server for downstream consumption.

✓ Setup - a one-time transformation mapping is built by ClearTax between your source format and the mandate-compliant representation.

✓ Operation - ClearTax pulls input files from the SFTP server on the frequency agreed at setup, applies the transformation, submits each invoice through the standard flows, and places output files (status responses, error reports, delivery confirmations) back on the SFTP server for your downstream systems to consume.
