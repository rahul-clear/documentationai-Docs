title: "Audit Trail"
description: "Invoice-level chronological event log for compliance and regulatory audits"
---

### Audit Trail:

<span style={{color: '#22c55e'}}>✓</span> ClearTax maintains an invoice-specific audit trail that records every event in the lifecycle of each invoice, providing a complete chronological record for compliance, review, and regulatory audits.

<span style={{color: '#22c55e'}}>✓</span> Events captured include system events, govt reporting events, status changes received from the counterparty's Access Point, and your team's own actions taken on the invoice.

<span style={{color: '#22c55e'}}>✓</span> Each audit entry includes a timestamp, a status badge indicating the outcome, and where applicable, the user who triggered the action.

<span style={{color: '#22c55e'}}>✓</span> Your team can access the audit trail through the ClearTax platform UI, viewing the complete chronological event log for any specific invoice.

### Audit Events API (add-on SKU):

<span style={{color: '#22c55e'}}>✓</span> The Audit Events API provides programmatic access to the same audit data - chronological event list per invoice, with optional filtering by event source (system, Access Point, FTA) and time range - for integration with your compliance monitoring or internal audit systems.
