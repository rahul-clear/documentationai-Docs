---
title: "Audit Trail"
description: "Invoice-level chronological event log for compliance and regulatory audits"
---

- ClearTax maintains an invoice-specific audit trail recording every event in an invoice's lifecycle, giving a complete chronological record for compliance, review, and regulatory audits.
- Events captured include system events, government reporting events, MLS/status changes received from the counterparty's Access Point, and your team's own actions on the invoice.
- Each entry includes a timestamp, a status badge indicating the outcome, and, where applicable, the user who triggered the action.
- Your team can view the complete chronological event log for any invoice directly on the ClearTax platform.
- **Audit Events API (additional SKU)** - programmatic access to the same audit data - a chronological event list per invoice, filterable by event source (system, Access Point, government) and time range - for integration with your compliance monitoring or internal audit systems.
