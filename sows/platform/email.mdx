### Send document via Email:

✓ The feature can be used to email exchanged documents (eInvoices). Documents are attached as PDFs.

-  As a Seller: Emails can be manually or auto-sent once the e-Invoice reaches the buyer network (Peppol).
- As a Buyer: Emails can be manually forwarded once the e-Invoice is received via the Peppol network.

✓ The email is triggered from ClearTax mailer services by default; the email server can be changed to your own server on demand, requiring a one-time setup and configuration.

✓ The email content is predefined as a generic message, with support for modification and multiple templates across different invoice types on request.

✓ Emails are by default sent in English (support for other languages can be requested via your ClearTax account manager)
