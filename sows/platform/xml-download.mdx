### XML Download:

<span style={{color: '#22c55e'}}>✓</span> Ability to download XML that has been transmitted to a counterparty access point. Downloaded files are the exact payloads transmitted, unchanged after transmission.

<span style={{color: '#22c55e'}}>✓</span> Available downloads per invoice include:

&nbsp;&nbsp;&nbsp;&nbsp;<span style={{color: '#22c55e'}}>✓</span> The XML sent to the counterparty Access Point for exchange

&nbsp;&nbsp;&nbsp;&nbsp;<span style={{color: '#22c55e'}}>✓</span> The geo specific meta data document (XML) submitted to the C5 Access Point

&nbsp;&nbsp;&nbsp;&nbsp;<span style={{color: '#22c55e'}}>✓</span> The response XMLs received for each exchange

<span style={{color: '#22c55e'}}>✓</span> XML versions of the documents exchanged can be accessed from the ClearTax platform UI, via APIs and via SFTP.
