---
title: XML Download
description: Download transmitted invoice and government-reporting XML payloads
---
✓ Ability to download XML that has been transmitted (or exchanged) to a counterparty access point. Downloaded files are the exact payloads transmitted, unchanged after transmission.

✓ Available downloads per invoice include:

    ✓ The XML sent to the counterparty Access Point for exchange

    ✓ The geo specific meta data document (XML) submitted to the C5 Access Point

    ✓ The response XMLs received for each exchange

✓ XML versions of the documents exchanged can be accessed from the ClearTax platform UI, via APIs and via SFTP.
