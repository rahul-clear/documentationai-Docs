*API documentation and reference material.*

## API Documentation

Full endpoint documentation covering authentication, e-invoice generation (JSON, XML, and async), device and certificate registration, code lists, and error handling.

**Environments:**

- **Sandbox**: `https://api-sandbox.cleartax.com/middle-east/ksa/einvoicing` (verify data at `https://app-sandbox.cleartax.com/middle-east/ksa/einvoicing/`)
- **Production**: `https://api.cleartax.com/middle-east/ksa/einvoicing` (verify data at `https://app.cleartax.com/middle-east/ksa/einvoicing/`)
- **SSL/TLS**: multidomain SAN certificate (`*.cleartax.com`), valid through 24 Feb 2027, TLS 1.2 supported.

**Current endpoints:** Generate E-Invoice (JSON), Generate E-Invoice Async (B2C), Generate E-Invoice via XML, Send Signed E-Invoice XML to ZATCA, Register Device, Get PCSID Generation Status, Renew PCSID, Get Invoice, Get Bulk Invoice Lite (up to 500 invoices/request), Get E-Invoice PDF, Get E-Invoice PDF/A-3 with PDF API, Send E-Invoice via Email, Add Business Units API.

**Legacy (Phase I only)**: Generate E-Invoice (Phase I), Generate QR Code (Phase I), Generate Device ID, Generate CSID and PCSID - valid only for Phase I; use the current endpoints above for new integrations.
