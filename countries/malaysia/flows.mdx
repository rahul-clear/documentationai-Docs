## Sales Side Flow

### B2B

Sales invoices are submitted via the **Generate E-Invoice** API (`einvoice-type=SALES`) - a bulk endpoint accepting up to 10 documents per call, in JSON or XML (UBL) format. ClearTax validates each document, submits it to LHDN for clearance, and shares it over the Peppol network if enabled. Each document returns a unique LHDN reference (UUID) once accepted.

### B2C

B2C invoices can go through the same **Generate E-Invoice** API with `einvoice-type=SALES_B2C`, or through the separate **Upload E-Invoice** API, which validates and persists invoice data without requiring full customer details upfront - useful when buyer information isn't available at the point of sale, or when invoices need to be consolidated before submission to LHDN.

## Purchase Side Flow

Self-billed purchase documents are supported via the **Generate E-Invoice** API using `einvoice-type=PURCHASE` - for cases where your business is required to self-bill on behalf of a supplier. Note that the **Upload E-Invoice** API is restricted to `SALES_B2C` only; purchase documents must go through the Generate endpoint.
