- You can generate self-billed documents through the Purchase documents section on ClearTax
- Select the "Purchase Documents" tile on the homepage or from the left-side panel to land on the purchase documents dashboard.
- Once you land on the "Purchase documents" dashboard, you can initiate your journey of generated self-billed documents on your seller's behalf for eligible scenarios.

## Import data

- You can import purchase data using the "Import" button on the left-side panel and clicking on the "Import Purchase documents" screen that appears on the right side of the screen.

- You can select a file to import the data for self-billing if you already have the template available. Alternatively, you can download the ClearTax template from the same screen.

- Once you have selected the file to be imported, you can select the "Einvoice Malaysia - Self Billed System Template" under the section "Template to be used" on the below screen.
- Click on "Check file for errors & duplicates" once all the selections are made.

- The import process will be initiated from ClearTax wherein ClearTax will run validations to check if the imported data is in compliance with LHDN e-invoicing requirements.
- It can take a few seconds based on the file size.

- Once all the validations are run on the imported data, you will see a "File Summary" screen where it will show the number of rows processed in the ingested file and their corresponding statuses.
- If there are any errors in any of the rows, you can fix those errors on the UI and click on "Proceed". Follow the steps as mentioned in the "B2B sales import section" for detailed steps on the same.
- If there are no errors, you can click on the "Import rows without errors" button.

- Once the import activity is successful, you will be able to see the imported data on the purchase documents dashboard page with the document statuses as "Not generated".
- Also note that the document type here will be "Self-billed" which you can see in the document type column on the dashboard.

## Generate self-billed e-invoice(s)

- You can select the documents for which you want to generate an e-invoice. You can generate e-invoices both individually and in bulk.
- Once you have selected the documents for which you want to generate a self-billed e-invoice(s), you can click on "Generate self-billed e-inv" under the "Actions" dropdown.\

## Cancel a self-billed e-invoice

- LHDN allows canceling a generated e-invoices within 72 hours from date & time of validation when the e-invoice becomes valid.
- You can choose the document for which you want to perform cancellation.
- Click on the "Actions" dropdown and choose "Cancel self-billed e-inv" option for canceling the document.

- Select the reason for cancellation and click on "Cancel e-inv" to proceed.

## Print e-invoice(s) & download report

### Print e-invoice(s)

- For printing any of the purchase documents, please follow the steps similar to the [B2B sales documents printing](https://docs.google.com/document/d/1QZ12HMgeEgUyh4Gm5S8jaRfBX1jqesjftUsvYOSGsII/edit#heading=h.mdtzsw5mfzo9) process.

### Download report

- You can download both detailed CSV & lite CSV reports from the "Actions" dropdown.

## Check purchase import history

- Navigate to the purchase import history page by clicking on the "Import history" option on the left-hand panel. Once you are inside the "Import history" page, switch to the "Purchase import history" tab.
- You can view and fix the errors in your imported file through this page.
- You can also view the documents that were imported as part of a file uploaded on ClearTax.
