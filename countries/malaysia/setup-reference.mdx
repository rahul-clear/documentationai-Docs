## API Documentation

- **Generate E-Invoice**: `POST {{HOST}}/einvoice/v1/documents/generate` - bulk submission (up to 10 documents), supports `dry-run` validation-only mode, versioned via `MY_GENERATE_UBL_2_1_V1`.
- **Upload E-Invoice**: `POST {{HOST}}/einvoice/v1/documents/upload` - validation and persistence without immediate LHDN submission (SALES_B2C only).
- **Auth**: `x-cleartax-auth-token`, `x-clear-tin`, optional `x-clear-branch` and `x-request-id` headers on every request.
- **Rate limits** (aligned with LHDN): Generate - Production 100 calls/min (burst 10), Sandbox 10 calls/min (burst 2). Upload - 500 calls/min (burst 25) in both environments.
- **Response codes**: 200 (submitted, with or without validation errors), 400 (invalid payload), 401 (unauthenticated), 403 (unauthorized - requires Admin role for the TIN), 429 (rate limited).

## Additional Details

- Each document accepts a `CustomFields` object (key-value pairs) for custom output PDF templates or reporting.
- Documents are matched to LHDN via a `UniqueIdentifier` (typically TIN + document number + document type + fiscal year).
- `AllowCancelledDocumentsGeneration` lets you re-generate documents that were previously cancelled.
