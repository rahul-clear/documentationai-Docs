ClearTax Poland has two dashboard-level surfaces you interact with daily:

1. Clear Finance Cloud landing page - the launcher for every Clear product. You pass through it to enter e-Invoicing.
2. E-Invoicing dashboard - the working home page inside the e-Invoicing app.

## Clear Finance Cloud landing page

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/poland/product-guide/dashboard-walkthrough/clear-finance-cloud-landing-page.jpg" width="1400" height="794" alt="Clear Finance Cloud landing page" />

### Header bar (top)

| Element                         | Purpose                                                  |
|---------------------------------|----------------------------------------------------------|
| App switcher (top-left)         | Return to this landing page from anywhere in the product |
| Demo workspace banner           | Appears only in a demo workspace                         |
| Language toggle                 | Switch UI language                                       |
| Bell icon                       | System notifications                                     |
| Workspace name pill (top-right) | Opens your account and workspace menu                    |

### Workspace and account menu

Click the workspace pill in the top-right to open your account panel. You'll see:

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/poland/product-guide/dashboard-walkthrough/workspace-and-account-menu.png" width="2048" height="1149" alt="Workspace and account menu" />

- **Your avatar and workspace name**
- **Account email**
- **Account & Security Settings** - password, MFA, session management
- **Your workspaces** - all workspaces you're a member of. Click Manage to open workspace settings.
- Logout of all workspaces

### Product cards

- **e-Invoicing** - "Generate E-Invoices within minutes." Click to enter the e-Invoicing dashboard.

### Right rail

- **Star + workspace name** - confirms the workspace you're operating in
- **Go to settings** - jump straight into workspace settings

## E-Invoicing dashboard

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/poland/product-guide/dashboard-walkthrough/e-invoicing-dashboard-poland.jpg" width="1280" height="731" alt="E-Invoicing dashboard (Poland)" />

### Top bar

| Element          | Purpose                                                                                                                 |
|------------------|-------------------------------------------------------------------------------------------------------------------------|
| App switcher     | Return to the Clear Finance Cloud landing page                                                                          |
| Country selector | Visible only for multi-country customers. Switch between Poland and your other markets (e.g. Germany, Croatia, Belgium) |
| NIP selector     | Shows the current entity name and its VAT number (PL + NIP). Click to switch NIP                                        |
| Language toggle  | Same as landing page                                                                                                    |
| Support Desk     | Raise a support ticket without leaving the product ([Support Desk](/countries/poland/product-guide/support-desk))                                                          |
| Bell icon        | E-Invoicing notifications                                                                                               |
| Workspace pill   | Same account menu as the landing page                                                                                   |

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/poland/product-guide/dashboard-walkthrough/country-selector-open.jpg" width="1280" height="731" alt="Country selector open" />

### NIP selector

Click the NIP pill to open the entity switcher. It lists every NIP registered in your workspace. All data on the dashboard rescopes to the NIP you select.

### Left sidebar

| Label              | What it does                                                         |
|--------------------|----------------------------------------------------------------------|
| Home               | Returns to this dashboard                                            |
| Sales Documents    | Manage all outbound invoices ([Sales Documents](/countries/poland/product-guide/sales-documents))                             |
| Purchase Documents | View invoices received from suppliers via KSeF ([Purchase Documents](/countries/poland/product-guide/purchase-documents))           |
| Reports            | Business insights and analytics ([Reports](/countries/poland/product-guide/reports))                          |
| Import             | Bulk upload invoices via file ([Importing Documents](/countries/poland/product-guide/importing-documents))                            |
| Import history     | Audit trail of past imports ([Importing Documents](/countries/poland/product-guide/importing-documents))                              |
| Settings (bottom)  | Workspace, users, integrations, notification preferences ([Settings](/countries/poland/product-guide/settings)) |
