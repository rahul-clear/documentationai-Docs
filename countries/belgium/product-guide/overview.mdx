Step by step guides on how to use the Peppol based ClearTax E-Invoicing solution for Belgium.

From January 1, 2026, all VAT-registered businesses in Belgium must be able to issue and receive structured electronic invoices for their B2B transactions. The mandate is built entirely on the Peppol network, and ClearTax is a certified Peppol Access Point.

| Detail | Information |
| --- | --- |
| Tax authority | FPS Finance (FOD Financiën) |
| Network | Peppol |
| Exchange model | Peppol 4-corner model |
| Format | Peppol BIS 3.0 (EN 16931) |
| Applies to | B2B invoices between VAT-registered businesses |
