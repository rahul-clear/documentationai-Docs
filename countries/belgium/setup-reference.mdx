## API Documentation

**Sandbox (QA/Testing)**: `https://api-sandbox.eu.cleartax.com` (port 443) - frontend at `https://app.eu.cleartax.com`

**Production**: `https://api.eu.cleartax.com` (port 443) - same frontend

SSL/TLS: multidomain SAN certificate covering `*.clear.in`, `*.cleartax.in`, `*.eu.cleartax.com`, valid through 24 Feb 2027, TLS 1.2 supported.

## Additional Details

- **Lifecycle actions** - invoice statuses and responses (Acknowledgement, Acceptance, Rejection) are communicated with counterparties using standard Peppol BIS Invoice Response 3.0 messages.
- **Registration and authentication via VAT** - ClearTax registers your Belgian Enterprise Number (KBO/BCE) and VAT number in the global Peppol Directory, so buyers and suppliers across Europe can discover your endpoint automatically.
- **Self-billed invoicing** - supported for buyer-issued invoicing under formal self-billing agreements, using the Peppol BIS Self-Billing specification.
- **Business scenarios** - covers the standard range defined under OpenPEPPOL and Belgian national extensions (VAT treatments, reverse charges, zero-rated sales, intra-community transactions, commercial discounts).
