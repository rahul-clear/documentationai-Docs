Belgium's e-invoicing mandate, run by FPS Finance (FOD Financiën), requires businesses to exchange invoices through the Peppol network via a certified Access Point (AP) such as ClearTax.

This page covers how sales and purchase invoices flow through the Peppol network (see [Flows](/countries/belgium/flows)), and API and platform reference material (see [Setup & Reference](/countries/belgium/setup-reference)).

**Regulatory basis:** Structured e-invoicing for domestic B2B transactions between VAT-registered businesses is mandatory from 1 January 2026, overseen by FPS Finance, using the Peppol network in EN 16931-compliant formats (UBL 2.1 or CII). A three-month tolerance period on penalties ended 31 March 2026. Source: [FPS Finance - E-invoicing](https://finance.belgium.be/en/enterprises/vat/e-invoicing)
