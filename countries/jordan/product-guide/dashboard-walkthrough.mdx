ClearTax Jordan has two dashboard-level surfaces you interact with daily:

1. **Clear Finance Cloud landing page** - the outer shell you land on when you log in. This is the launcher for every Clear product; you'll pass through it to enter e-Invoicing.
2. **E-Invoicing dashboard** - the working home page inside the e-Invoicing app. This is where you'll spend most of your time.

## Clear Finance Cloud landing page

When you log in, you land here. It's your home for all Clear products, of which e-Invoicing is one.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/jordan/product-guide/dashboard-walkthrough/landing-page.jpg" width="1400" height="794" alt="Clear Finance Cloud landing page" />

### Header bar (top)

| Element | Purpose |
| --- | --- |
| App switcher (top-left) | Return to this landing page from anywhere in the product |
| Demo workspace banner | Appears only when you're in a demo workspace. Live workspaces don't show this banner. |
| Language toggle | Switch UI language between English and Arabic |
| Bell icon | System notifications |
| Workspace name pill (top-right) | Opens your account and workspace menu |

### Workspace and account menu

Click the workspace pill in the top-right to open your account panel.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/jordan/product-guide/dashboard-walkthrough/account-menu.jpg" width="1400" height="793" alt="Workspace/account dropdown open" />

You'll see:

- **Your avatar and workspace name** at the top
- **Account email** (the email you signed up with)
- **Account & Security Settings** - password, MFA, session management
- **Your workspaces** list - shows all workspaces you're a member of. The one marked "Demo" and "This Is Your Default Workspace" is your current one. Click Manage to open workspace settings.
- Logout of all workspaces

### Language toggle

Click EN in the header to switch the UI between English and Arabic.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/jordan/product-guide/dashboard-walkthrough/language-toggle.jpg" width="1400" height="798" alt="English / Arabic toggle open" />

Arabic switches the entire interface to right-to-left (RTL) layout.

### Product cards

Under Clear Compliance Cloud, you'll see product tiles. Each tile represents a ClearTax product you're licensed for.

- **e-Invoicing** - "Generate E-Invoices within minutes." Click this to enter the e-Invoicing dashboard.

Additional products (e.g. reconciliation, filing, analytics) will surface here as you add them to your workspace.

### Right rail

- **Star + workspace name** (top-right corner) - visual confirmation of the workspace you're operating in
- **Go to settings** - jump straight into workspace settings

## E-Invoicing dashboard

Click the e-Invoicing card to enter the working dashboard.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/jordan/product-guide/dashboard-walkthrough/einvoicing-dashboard.png" width="2048" height="623" alt="E-Invoicing dashboard" />

### Top bar

| Element | Purpose |
| --- | --- |
| App switcher | Return to the Clear Finance Cloud landing page |
| Country selector | Visible only for multi-country customers; switch between markets |
| TIN / Branch selector | Shows the current entity; click to switch TIN or Income Source |
| Language toggle | Same as landing page |
| Support Desk | Raise a support ticket without leaving the product (see [Support Desk](/countries/jordan/product-guide/support-desk)) |
| Bell icon | E-Invoicing-specific notifications |
| Workspace pill | Same account menu as the landing page |

### TIN / Branch selector

Click the TIN pill to open the entity switcher. It shows your registered TIN(s) and, under each, the Income Sources (branches) you've added credentials for. All data on the dashboard rescopes to whatever you select.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/jordan/product-guide/dashboard-walkthrough/tin-branch-selector.png" width="2048" height="623" alt="TIN / Branch selector dropdown" />

The dropdown shows:

- **Parent entity** (e.g. abcd TIN: 102102110) - click the arrow to expand branches
- **Branches** under each entity (e.g. 003) - select a branch to scope the dashboard to that branch's data
- **Additional entities** (e.g. Test 123...) - switch entirely to another registered TIN

All data on the dashboard rescopes to whatever you select.

### Left sidebar

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/jordan/product-guide/dashboard-walkthrough/left-sidebar.png" width="2048" height="1155" alt="Left sidebar navigation" />

| Label | What it does |
| --- | --- |
| Home | Returns to this dashboard |
| Sales Documents | Manage all outbound invoices (see [Sales Documents](/countries/jordan/product-guide/sales-documents)) |

| Settings (bottom) | Workspace, users, integrations, notification preferences (see [Settings](/countries/jordan/product-guide/settings)) |

### Announcements panel

Shows platform-wide product announcements, release notes, and outage/incident notices from the ClearTax team. When there are none, you'll see the sleeping "Z" icon and "No announcements yet. New announcements will appear here."
