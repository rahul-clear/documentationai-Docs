Onboarding sets up your workspace on ClearTax and connects it to JoFotara so ClearTax can generate and clear your e-invoices in real time. You'll need an ISTD account and a JoFotara device (branch) registration before you can connect ClearTax - this only needs to be done once per TIN.

## Prerequisites

Before you begin, make sure you have:

- An [ISTD e-Tax Portal](https://etax.istd.gov.jo/Signup.aspx) account, verified against your Tax ID / TIN
- A [JoFotara](https://portal.jofotara.gov.jo/en/login) device (branch) registration, with a Client ID and Client Secret for at least one Income Source
- Access to the ClearTax Jordan URL: [https://app.mea.cleartax.com/new-einvoicing](https://app.mea.cleartax.com/new-einvoicing)

## Before you begin: get your JoFotara credentials

### A. Create your ISTD account

Visit the ISTD e-Tax Portal: [https://etax.istd.gov.jo/Signup.aspx](https://etax.istd.gov.jo/Signup.aspx)

1. Go to the ISTD e-Tax Portal.
2. Enter your official Tax ID / TIN (8, 9, or 15 digits).
3. Follow the prompts to verify your details.
4. Set your username and password, and confirm to finish.

### B. Register your device on JoFotara

After ISTD setup, you'll be redirected to the JoFotara Portal: [https://portal.jofotara.gov.jo/en/login](https://portal.jofotara.gov.jo/en/login)

1. Log in using the Taxpayer number, username, and password you created on ISTD.
2. Click "Integrate Device", then "Link A New Device."
3. Enter your username and your Income Source Sequence (branch code), then click "Add."
4. JoFotara generates a Client ID and Client Secret for that device - copy both.

**Keep these safe.** Each branch (Income Source) has its own Client ID and Client Secret. You'll enter these into ClearTax in Step 5 below - invoices can't be generated for a branch until its credentials are added.

## Set up ClearTax (first-time setup)

The first time you log in, ClearTax walks you through a short setup flow.

### Step 1 - Welcome

Review the product highlights and click Continue.

### Step 2 - Select your country

Choose Jordan as your primary country, then click Add country.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/jordan/product-guide/onboarding/select-country.png" width="2046" height="1162" alt="Select your first country - Jordan" />

### Step 3 - Create your business profile

Enter your Organisation Identifier (TIN) and Organisation Name exactly as registered with ISTD, then click Next.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/jordan/product-guide/onboarding/business-profile.png" width="2046" height="1162" alt="Create business profile - TIN and Organisation Name" />

### Step 4 - Add your Income Source Sequence

Enter the Income Source Sequence (branch code) you registered on JoFotara, then click Next.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/jordan/product-guide/onboarding/income-source-sequence.png" width="2046" height="1162" alt="Add Income Source Sequence" />

### Step 5 - Add your API credentials

Enter the Client ID and Client Secret generated by JoFotara for this branch, then click Continue to Dashboard. If you don't have credentials yet, use the "Go to JoFotara Portal" link on this screen.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/jordan/product-guide/onboarding/api-credentials.png" width="2046" height="1162" alt="Add API credentials - Client ID and Client Secret" />

**Testing in a demo account?** If you're setting up a test/demo account, your API credentials should start with "MOCK-" and the Invoice Number should start with "MOCK-PASS".

## Understanding the business hierarchy

| Field | Description | Example |
| --- | --- | --- |
| TIN | Your taxpayer ID | 1234567890 |
| Income Source Sequence | ISTD-assigned branch code | 001 |
| Client ID | Device identifier from JoFotara | CT-MAF-AMM-01 |
| Client Secret | Paired secure key for that device | sk_live_xxxxx |

- One TIN links to one JoFotara account, which can have multiple branches (Income Sources / devices).
- Each branch has its own Client ID, Client Secret, and Income Source Sequence.
- Credentials must be added for every Income Source - invoices cannot be generated without this step.

## Adding more TINs, countries, or branches later

Already completed setup and need to add another entity? Everything below is managed from **Settings > Business settings**.

### Add a new country

1. Go to Settings > Business settings.
2. Use the Add / Switch Country dropdown and select Add a Country.
3. Choose the country and click Save and Proceed.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/jordan/product-guide/onboarding/add-country.png" width="2046" height="1162" alt="Add a new country from Business settings" />

### Add a new TIN

1. On the Business settings page, click Add business.
2. Choose Add new TIN.
3. Enter the TIN and Organisation Name, then click Save.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/jordan/product-guide/onboarding/add-tin-1.jpg" width="1352" height="768" alt="Add new TIN - choose Add new TIN" />

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/jordan/product-guide/onboarding/add-tin-2.png" width="2046" height="1162" alt="Add new TIN - enter TIN and Organisation Name" />

### Add an Income Source to an existing TIN

1. On the Business settings page, find the TIN and click Add Income Source.
2. Confirm the TIN, enter the Income Source Sequence, then click Save.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/jordan/product-guide/onboarding/add-income-source-1.png" width="2046" height="1162" alt="Add Income Source - confirm TIN" />

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/jordan/product-guide/onboarding/add-income-source-2.png" width="2046" height="1162" alt="Add Income Source - enter Income Source Sequence" />

## Managing API credentials

Credentials can be added or updated at any time from **Settings > API Credentials**.

1. Go to Settings > API Credentials and switch to Jordan (JO).
2. Click Configure Credentials.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/jordan/product-guide/onboarding/api-credentials-configure.png" width="2046" height="1162" alt="Configure Credentials for Jordan" />

3. Select the TIN and Income Source, then enter the Client ID and Client Secret from JoFotara.
4. Click Save Configuration.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/jordan/product-guide/onboarding/api-credentials-save.png" width="2046" height="1162" alt="Save API credentials configuration" />

**Automatic verification.** Credentials are verified automatically once your first invoice for that Income Source is successfully generated - no separate test step is required.
