## Overview

ClearTax Germany has two dashboard-level surfaces you interact with daily:

- Clear Finance Cloud landing page - the outer shell you land on when you log in. This is the launcher for every ClearTax product; you’ll pass through it to enter e-Invoicing.

- E-Invoicing dashboard - the working home page inside the e-Invoicing app. This is where you’ll spend most of your time.

This section walks through every element of both surfaces so you know exactly what each control does.

## Clear Finance Cloud landing page

When you log in, you land here. It’s your home for all Clear products, of which e-Invoicing is one.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/germany/product-guide/dashboard-walkthrough/clear-finance-cloud-landing-page.jpg" width="1400" height="798" alt="Clear Finance Cloud landing page" />

### Header bar (top)

| **Element**                                      | **Purpose**                                                                                                |
|--------------------------------------------------|------------------------------------------------------------------------------------------------------------|
| App switcher (⋮⋮⋮ icon, top-left)                | Return to this landing page from anywhere in the product                                                   |
| Clear Finance Cloud (label)                      | Confirms which product suite you’re in                                                                     |
| Demo workspace banner (yellow strip)             | Appears only when you’re in a demo workspace. Live workspaces don’t show this banner.                      |
| EN language toggle                               | Switch UI language between English and Deutsch or Francais etc                                             |
| Bell icon                                        | System notifications (individual notification behaviours are called out in the relevant workflow sections) |
| Workspace name pill (top-right, e.g. "ClearTax") | Opens your account and workspace menu                                                                      |

### Workspace and account menu

Click the workspace pill in the top-right to open your account panel.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/germany/product-guide/dashboard-walkthrough/workspace-account-dropdown-open.jpg" width="1400" height="765" alt="Workspace/account dropdown open" />

You’ll see:

- **Your avatar and workspace name** at the top

- **Account email** (the email you signed up with)

- **Account & Security Settings** - password, MFA, session management

- **Your workspaces** list - shows all workspaces you’re a member of. The one marked "Demo" and "This Is Your Default Workspace" is your current one. Click Manage to open workspace settings.

- Logout of all workspaces

### Language toggle

Click EN in the header to switch the UI between English and Deutsch or other languages.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/germany/product-guide/dashboard-walkthrough/language-toggle.jpg" width="1400" height="766" alt="Language toggle" />

### Product cards

Under Clear Compliance Cloud, you’ll see product tiles. Each tile represents a ClearTax product you’re licensed for.

- **e-Invoicing** - "Generate E-Invoices within minutes." Click this to enter the e-Invoicing dashboard.

Additional products (e.g. reconciliation, filing, analytics) will surface here as you add them to your workspace.

### Right rail

- **Star + workspace name** (top-right corner) - visual confirmation of the workspace you’re operating in

- **Go to settings** - jump straight into workspace settings

## E-Invoicing dashboard

Click the e-Invoicing card to enter the working dashboard.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/germany/product-guide/dashboard-walkthrough/e-invoicing-dashboard-including-support-.jpg" width="1400" height="334" alt="E-Invoicing dashboard including Support Desk" />

### Top bar

| **Element**                | **Purpose**                                                                                                                                       |
|----------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------|
| App switcher (⋮⋮⋮)         | Return to the Clear Finance Cloud landing page                                                                                                    |
| E-Invoicing label          | Confirms you’re inside the e-Invoicing app                                                                                                        |
| Country selector (Germany) | Visible only for multi-country customers. If you operate across EU markets, switch country here. Single-country customers won’t see this control. |
| VAT / Branch selector      | Shows current entity - e.g. VAT: DE221232418. Click to switch entities or branches.                                                               |
| EN language toggle         | Same as landing page                                                                                                                              |
| Support Desk               | Raise a support ticket with ClearTax without leaving the product. Opens the support console.                                                      |
| Bell icon                  | E-Invoicing–specific notifications                                                                                                                |
| Workspace pill             | Same account menu as landing page                                                                                                                 |

### VAT / Branch selector

Click the VAT dropdown to open the entity switcher. The search box lets you filter by VAT or branch name.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/germany/product-guide/dashboard-walkthrough/vat-branch-search-open.jpg" width="1400" height="765" alt="VAT/Branch search open" />

The dropdown shows:

- **Parent entity** (e.g. VAT: DE221232418) - click the arrow to expand to see branches below the VATs

- **Branches** under each entity (e.g. Branch1) - select a branch to scope the dashboard to that branch’s data

- **Additional entities** (e.g. Purchase) - switch entirely to another registered VAT

All data on the dashboard rescopes to whatever you select.

### Left sidebar

Hover the sidebar (or click the expand icon) to reveal navigation labels.

### Sales documents summary tile

The primary tile on the left of the main area.

Header: "Sales documents - Manage and take action on all sales documents" with a &gt; shortcut to the full Sales Documents list.

Total documents shows the count over the selected window (default: Last 30 days). A colour-coded stacked bar breaks down the total by status:

| **Status**                    | **What it means**                                              |
|-------------------------------|----------------------------------------------------------------|
| Pending                       | Awaiting submission (queued, retrying, or manual review)       |
| Failed                        | Submission or validation failed - needs remediation            |
| Submitted to exchange network | Sent to Peppol / ClearTax has handed off to the network        |
| Delivered to buyer network    | Reached the buyer’s Access Point (C3)                          |
| Delivered to buyer            | Reached the buyer’s ERP or system (C4)                         |
| Received                      | An invoice has arrived from a buyer via Peppol and been stored |

### Purchase documents summary tile

Parallel to the Sales tile, on the right. Header: "Purchase documents - Manage and take action on all purchase documents" with a &gt; shortcut to the full Purchase Documents list. Total documents and window are the same as the Sales tile.

| **Status**                    | **What it means**                                                            |
|-------------------------------|------------------------------------------------------------------------------|
| Received                      | An invoice has arrived from a supplier via Peppol and been stored            |
| Pending                       | Self Billed invoice awaiting submission (queued, retrying, or manual review) |
| Failed                        | Self Billed invoice submission or validation failed - needs remediation      |
| Submitted to exchange network | Self Billed invoice sent to Peppol / ClearTax has handed off to the network  |
| Delivered to buyer network    | Self Billed invoice reached the buyer’s Access Point (C3)                    |
| Delivered to buyer            | Self Billed invoice reached the buyer’s ERP or system (C4)                   |

### Announcements panel (right rail)

Shows platform-wide product announcements, release notes, and outage/incident notices from the ClearTax team. When there are none, you’ll see the sleeping "Z" icon and "No announcements yet. New announcements will appear here."

### Business insights and analytics

| **Tile**      | **What it does**                                                                                                          |
|---------------|---------------------------------------------------------------------------------------------------------------------------|
| MIS Dashboard | Detailed insights and breakdown of sales and purchase documents. Deeper analytics live under Reports in the left sidebar. |

### Reconciliation

| **Tile**             | **What it does**                                                                                  | **Notes**     |
|----------------------|---------------------------------------------------------------------------------------------------|---------------|
| SR vs Einvoice recon | Reconcile your Sales Register (ERP-side data) against Sales e-invoices submitted through ClearTax | 🔒 Paid add-on |
| PR vs Einvoice recon | Reconcile your Purchase Register against Purchase e-invoices received via ClearTax                | 🔒 Paid add-on |

Tiles marked with a padlock 🔒 are paid add-ons. To enable them, contact your ClearTax point of contact to understand next steps.

## Navigation reference

| **I want to…**                            | **Go to**                                          |
|-------------------------------------------|----------------------------------------------------|
| See all my outbound invoices              | Left sidebar → Sales Documents                     |
| See all my inbound invoices               | Left sidebar → Purchase Documents                  |
| Upload invoices in bulk                   | Left sidebar → Import                              |
| Check whether a past import succeeded     | Left sidebar → Import history                      |
| See analytics and trends                  | Left sidebar → Reports → MIS Dashboard             |
| Reconcile ERP data with what ClearTax has | Dashboard → SR vs Einvoice or PR vs Einvoice tiles |
| Switch between entities or branches       | Top bar → VAT / Branch selector                    |
| Change UI language                        | Top bar → EN toggle                                |
| Manage users, integrations, notifications | Sidebar bottom → Settings (gear icon)              |
| Read release notes                        | Dashboard → Product release notes tile             |
| Raise a support ticket                    | Top bar → Support Desk                             |
