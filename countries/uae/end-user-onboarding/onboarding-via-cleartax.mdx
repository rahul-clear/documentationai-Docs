---
title: Onboarding via ClearTax
description: 'Step-by-step flow for a UAE taxpayer onboarding ClearTax as ASP starting from ClearTax'
---
In this scenario the user begins onboarding on ClearTax and sets up an account. While setting up the business profile for the account (i.e. the TRN), the user is redirected to the EmaraTax portal, where they select ClearTax as ASP and get redirected back to ClearTax to complete the onboarding process.

Below are the detailed steps:

### Step 1: Create an account

The user lands on the ClearTax product using the URL [https://app.mea.cleartax.com/new-einvoicing](https://app.mea.cleartax.com/new-einvoicing) and is asked to set up an account. The user provides the email address on which the account will be set up and clicks on "Continue". It is advisable to use the same email address as the admin email address on EmaraTax, since verification and mapping will happen only against that email ID.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/onboarding/sign-up.jpg" width="1400" height="699" alt="Create account on ClearTax" />

### Step 2: Password setup

The user enters a password and reconfirms it to set up the account. Along with password creation the user has to read and accept the terms & conditions for using the ClearTax e-Invoicing solution. Once this is done the user has to click on "Agree and continue" to create an account.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/onboarding/password-setup.jpg" width="1400" height="697" alt="Password setup and terms acceptance on ClearTax" />

### Step 3: Workspace name and account setup

Now the user sets up the account with the legal name that will be used for the workspace. The user also selects the rough turnover applicable for their enterprise.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/onboarding/workspace-setup.jpg" width="1400" height="700" alt="Workspace legal name and turnover setup" />

### Step 4: Personalisation

The user has to provide the profile details after setting the legal name and turnover. The user's profile is set up by taking the name and the designation.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/onboarding/personalise-profile.jpg" width="1400" height="700" alt="Personalisation - name and designation" />

### Step 5: Welcome page

Now the account is created on ClearTax and the user lands on the welcome page, with a welcome screen showing an e-Invoicing card. The user clicks on the e-Invoicing option.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/onboarding/welcome-popup-1.jpg" width="1400" height="698" alt="Welcome screen with e-Invoicing card" />

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/onboarding/welcome-popup-2.jpg" width="1400" height="701" alt="Welcome screen - e-Invoicing option selected" />

### Step 6: Business profile setup

Upon clicking on the e-Invoicing option, the user is asked to set up the business profile, which requires the TRN to be added to the account after verification by EmaraTax. The user is given basic details of e-Invoicing and requested to go to EmaraTax to onboard ClearTax as ASP to begin the exchange of e-invoices. Clicking on "Go to EmaraTax" takes the user to EmaraTax.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/onboarding/select-country.jpg" width="1400" height="798" alt="Business profile setup with Go to EmaraTax action" />

### Step 7: Login to EmaraTax

Admin user of the taxpayer logs in to the EmaraTax portal of FTA-UAE by entering their credentials and captcha.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/onboarding/emaratax-login.jpg" width="1400" height="696" alt="EmaraTax login screen" />

### Step 8: Select e-Invoicing

User lands on the homepage of EmaraTax and chooses e-Invoicing since they need to begin with the process of e-Invoicing.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/onboarding/emaratax-e-invoicing-menu.jpg" width="1400" height="698" alt="EmaraTax homepage with e-Invoicing option" />

### Step 9: Click on Proceed

EmaraTax portal gives details of the actions that are possible while on the e-Invoicing page, to which the user clicks on "Proceed" to move to the actual page.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/onboarding/action-required-modal.jpg" width="1400" height="698" alt="EmaraTax e-Invoicing page Proceed action" />

### Step 10: Select TIN

The user selects the TIN for which they want to start e-Invoicing, from the dropdown list containing the list of all TINs that are mapped in the EmaraTax account.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/onboarding/select-tin.jpg" width="1400" height="700" alt="TIN selection dropdown on EmaraTax" />

### Step 11: Selection of "Defmacro" as ASP

After selecting the TIN the user sees the list of available ASPs. The user has to navigate to the page where ClearTax appears, listed under its legal entity name "Defmacro" - this is expected. After selecting the radio button against "Defmacro", the user clicks on "Proceed to ASP".

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/onboarding/select-defmacro-asp.jpg" width="1400" height="701" alt="Selecting Defmacro (ClearTax) as ASP on EmaraTax" />

### Step 12: Confirmation of redirection to ClearTax

After clicking on "Proceed to ASP" a popup message appears on EmaraTax to indicate that the user will be redirected to the ASP website. The user clicks on "Yes" to continue the next steps of the onboarding process on ClearTax.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/onboarding/confirm-redirect.jpg" width="1400" height="701" alt="Redirect confirmation popup on EmaraTax" />

### Step 13: Linking request on ClearTax

The user is redirected to ClearTax, which opens the "Linking request" page. Here the user enters the registered EmaraTax email address, TIN number, and phone number, with phone number being optional. After entering the correct details the user clicks on "Verify applicant details".

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/onboarding/linking-request-form.jpg" width="1400" height="875" alt="ClearTax Linking request page" />

### Step 14: Confirmation of details

Once all the details are correctly entered, the user will see the taxpayer information as per EmaraTax displayed on the screen. The user can check all the details and select the declaration check box to click on "Submit" in order to proceed further.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/onboarding/confirm-details-unchecked.jpg" width="1400" height="701" alt="Taxpayer details fetched from EmaraTax" />

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/onboarding/confirm-details-checked.jpg" width="1400" height="691" alt="Declaration checkbox and Submit on ClearTax" />

### Step 15: Complete verification and Peppol ID creation

The taxpayer information is verified by EmaraTax. Once this is done a Peppol participant ID will be generated for the taxpayer and registered in the central directory of the FTA. After all these steps are completed a success message will be displayed. The user has to click on "Get Started" to proceed further.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/onboarding/peppol-id-created.jpg" width="1400" height="697" alt="Verification success and Peppol ID creation" />

### Step 16: Prefilled business profile

After successful completion of the linking request as per EmaraTax, the TRN and organisation name of the taxpayer will be prefilled in the business profile setup page of ClearTax. The user can verify this and then click on "Dashboard" to begin with e-Invoice generation.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/onboarding/business-profile-vat-type.png" width="1400" height="700" alt="Business profile prefilled with TRN and organisation name" />

### Step 17: e-Invoice dashboard

The user lands on the e-Invoice dashboard, where an overview of sales and purchase documents is present along with a host of other options and shortcuts. The user can begin exchanging invoices by uploading data or through the API/FTP method of data upload.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/onboarding/dashboard.jpg" width="1400" height="699" alt="ClearTax e-Invoice dashboard" />
