This section covers scenarios of a taxpayer in the UAE onboarding ClearTax as an accredited service provider (ASP) of e-invoicing on behalf of EmaraTax. It covers the two entry points into the onboarding flow, the possible error scenarios, and how they are handled so the user can clearly understand the error reason and navigate through successfully.

## Onboarding entry points

| Flow | Starting point |
| --- | --- |
| [Onboarding via EmaraTax](/countries/uae/end-user-onboarding/onboarding-via-emaratax) | Taxpayer admin begins on the EmaraTax portal and is redirected to ClearTax to complete setup |
| [Onboarding via ClearTax](/countries/uae/end-user-onboarding/onboarding-via-cleartax) | Taxpayer admin begins on ClearTax and is redirected to EmaraTax to link the TRN before returning to ClearTax |

See [Error Scenarios](/countries/uae/end-user-onboarding/error-scenarios) for validation failures that can occur during either flow.
