---
title: Onboarding via EmaraTax
description: 'Step-by-step flow for a UAE taxpayer onboarding ClearTax as ASP starting from the EmaraTax portal'
---
This is the first scenario, in which the taxpayer admin user begins the process of onboarding an ASP from EmaraTax.

### Step 1: Login to EmaraTax

Admin user of the taxpayer logs in to the EmaraTax portal of FTA-UAE by entering their credentials and captcha.

### Step 2: Select e-Invoicing

User lands on the homepage of EmaraTax and chooses e-Invoicing since they need to begin with the process of e-Invoicing.

### Step 3: Click on Proceed

EmaraTax portal gives details of the actions that are possible while on the e-Invoicing page, to which the user clicks on "Proceed" to move to the actual page.

### Step 4: Select TIN

The user selects the TIN for which they want to start e-Invoicing, from the dropdown list containing the list of all TINs that are mapped in the EmaraTax account.

### Step 5: Selection of "Defmacro" as ASP

After selecting the TIN the user sees the list of available ASPs. The user has to navigate to the third page to locate ClearTax, which is displayed as "Defmacro". After selecting the radio button against "Defmacro", the user clicks on "Proceed to ASP".

### Step 6: Confirmation of redirection to ClearTax

After clicking on "Proceed to ASP" a popup message appears on EmaraTax to indicate that the user will be redirected to the ASP website. The user clicks on "Yes" to continue the next steps of the onboarding process on ClearTax.

### Step 7: Linking request on ClearTax

The user will be redirected to ClearTax, which opens the "Linking request" page. Here the user will enter the registered EmaraTax email address, TIN number, and phone number, with phone number being optional. After entering the correct details the user clicks on "Verify applicant details".

### Step 8: Confirmation of details

Once all the details are correctly entered, the user will see the taxpayer information as per EmaraTax displayed on the screen. The user can check all the details and select the declaration check box to click on "Submit" in order to proceed further.

### Step 9: Complete verification and Peppol ID creation

The taxpayer information is verified by EmaraTax. Once this is done a Peppol participant ID will be generated for the taxpayer and registered in the central directory of the FTA. After all these steps are completed a success message will be displayed. The user has to click on "Get Started" to proceed further.

### Step 10: Creation of account on ClearTax

Now the setup of ClearTax as ASP on behalf of FTA is complete, and clicking on "Get Started" will take the user to ClearTax to start with e-Invoicing for the TIN-TRN combo that was onboarded. If the user has an existing account on ClearTax then the user is requested to log in, or else the user can set up an account on ClearTax.

### Step 11: Creating a password

Once the user confirms the email address, the user is required to create a password for the account. Along with password creation the user has to read and accept the terms & conditions for using the ClearTax e-Invoicing solution. Once this is done the user has to click on "Agree and continue" to create an account.

### Step 12: Account setup on ClearTax

Now the user account is complete with prefilled information of legal name that was fetched earlier from EmaraTax. The user has to select the turnover applicable for their enterprise.

### Step 13: Personalisation and profile setup

Once the name of the workspace and turnover is set up, the user has to provide the profile details. The user's profile is set up by taking the name and the designation.

### Step 14: Welcome page

Now the account is created on ClearTax and the user can start with e-Invoicing. The user will see a welcome screen with an e-Invoicing card. The user will click on the e-Invoicing option.

### Step 15: Business profile setup

The user will proceed to e-Invoicing to get the basic information about e-Invoicing and how it works. Upon clicking on the "Continue" button, the user will be taken to the "Business profile" page in which the TRN and organisation name will be prefilled as per the details fetched from EmaraTax. The user will not be able to edit this information as the tax registration number and entity name are exactly the same as the details on EmaraTax. Both of these details will be used while generating e-invoices.

### Step 16: Completion of onboarding and landing to E-Invoice

The business profile of the user is set up the same as the details in EmaraTax, and the user is taken to the ClearTax e-Invoice dashboard where both sales and purchase documents can be seen along with shortcuts to different features.

With this, the setup of the account on ClearTax is complete, with the taxpayer onboarding ClearTax as ASP via EmaraTax.
