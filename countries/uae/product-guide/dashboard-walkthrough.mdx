ClearTax UAE has two dashboard-level surfaces you interact with daily:

1. **Clear Finance Cloud landing page** - the outer shell you land on when you log in. This is the launcher for every ClearTax product; you'll pass through it to enter e-Invoicing.
2. **E-Invoicing dashboard** - the working home page inside the e-Invoicing app. This is where you'll spend most of your time.

This section walks through every element of both surfaces so you know exactly what each control does.

## Clear Finance Cloud landing page

When you log in, you land here. It's your home for all Clear products, of which e-Invoicing is one.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/dashboard-walkthrough/clear-finance-cloud-landing.jpg" width="1400" height="794" alt="Full Clear Finance Cloud landing page" />

### Header bar (top)

| Element | Purpose |
| --- | --- |
| App switcher (top-left) | Return to this landing page from anywhere in the product |
| Demo workspace banner (yellow strip) | Appears only when you're in a demo workspace. Live workspaces don't show this banner. |
| EN language toggle | Switch UI language between English and Arabic (&#x639;&#x631;&#x628;&#x64A;) |
| Bell icon | System notifications |
| Workspace name pill (top-right) | Opens your account and workspace menu |

### Workspace and account menu

Click the workspace pill in the top-right to open your account panel.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/dashboard-walkthrough/workspace-account-menu.jpg" width="1400" height="793" alt="Workspace/account dropdown open" />

You'll see:

- **Your avatar and workspace name** at the top
- **Account email** (the email you signed up with)
- **Account & Security Settings** - password, MFA, session management
- **Your workspaces** list - shows all workspaces you're a member of. The one marked "Demo" and "This Is Your Default Workspace" is your current one. Click Manage to open workspace settings.
- Logout of all workspaces

### Language toggle

Click EN in the header to switch the UI between English and Arabic.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/dashboard-walkthrough/language-toggle.jpg" width="1400" height="798" alt="English / Arabic toggle open" />

Arabic switches the entire interface to right-to-left (RTL) layout.

### Product cards

Under Clear Compliance Cloud, you'll see product tiles. Each tile represents a ClearTax product you're licensed for.

- **e-Invoicing** - "Generate E-Invoices within minutes." Click this to enter the e-Invoicing dashboard.

Additional products (e.g. reconciliation, filing, analytics) will surface here as you add them to your workspace.

### Right rail

- **Star + workspace name** (top-right corner) - visual confirmation of the workspace you're operating in
- **Go to settings** - jump straight into workspace settings

## E-Invoicing dashboard

Click the e-Invoicing card to enter the working dashboard.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/dashboard-walkthrough/einvoicing-dashboard.jpg" width="1400" height="310" alt="E-Invoicing dashboard including Support Desk" />

### Top bar

| Element | Purpose |
| --- | --- |
| App switcher | Return to the Clear Finance Cloud landing page |
| Country selector (UAE) | Visible only for multi-country customers. If you operate across MEA markets, switch countries here. Single-country customers won't see this control. |
| TRN / Branch selector | Shows current entity - e.g. Defmacro T&hellip; TRN: 104779803400003. Click to switch entities or branches. |
| EN language toggle | Same as landing page |
| Support Desk | Raise a support ticket with ClearTax without leaving the product. Opens the support console (see [Support Desk](/countries/uae/product-guide/support-desk)). |
| Bell icon | E-Invoicing-specific notifications |
| Workspace pill | Same account menu as landing page |

### TRN / Branch selector

Click the TRN pill to open the entity switcher. The search box lets you filter by TRN or branch name.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/dashboard-walkthrough/trn-branch-selector.jpg" width="1400" height="795" alt="TRN/Branch search open" />

The dropdown shows:

- **Parent entity** (e.g. abcd TRN: 102102102102003) - click the arrow to expand branches
- **Branches** under each entity (e.g. Branch1) - select a branch to scope the dashboard to that branch's data
- **Additional entities** (e.g. Defmacro T&hellip;) - switch entirely to another registered TRN

All data on the dashboard rescopes to whatever you select.

### Left sidebar

Hover the sidebar (or click the expand icon) to reveal navigation labels.

<Image src="https://raw.githubusercontent.com/rahul-clear/documentationai-Docs/main/images/countries/uae/product-guide/dashboard-walkthrough/left-sidebar.jpg" width="1400" height="795" alt="Left sidebar expanded" />

| Label | What it does |
| --- | --- |
| Home | Returns to this dashboard |
| Sales Documents | Manage all outbound invoices, credit notes, debit notes ([Sales Documents](/countries/uae/product-guide/sales-documents)) |
| Purchase Documents | Manage all inbound invoices from your suppliers ([Purchase Documents](/countries/uae/product-guide/purchase-documents)) |
| Reports | Business insights, analytics ([Reports](/countries/uae/product-guide/reports)) |
| Import | Bulk upload invoices via file ([Importing Documents](/countries/uae/product-guide/importing-documents)) |
| Import history | Audit trail of past imports ([Importing Documents](/countries/uae/product-guide/importing-documents)) |
| Settings (bottom) | Workspace, users, integrations, notification preferences ([Settings](/countries/uae/product-guide/settings)) |

### Announcements panel (right rail)

Shows platform-wide product announcements, release notes, and outage/incident notices from the ClearTax team. When there are none, you'll see the sleeping "Z" icon and "No announcements yet. New announcements will appear here."
