This product guide walks through the ClearTax UAE e-Invoicing product end to end - from creating a workspace and linking it to EmaraTax, through day-to-day use of the dashboard, Sales and Purchase Documents, bulk imports, reporting, workspace settings, and the built-in support desk.

## Sections

| Section                                                                     | Covers                                                                                                                |
| --------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| [Onboarding](/countries/uae/product-guide/onboarding)                       | Creating a ClearTax account and linking your TRN via EmaraTax to register as an Accredited Service Provider (ASP)     |
| [Dashboard Walkthrough](/countries/uae/product-guide/dashboard-walkthrough) | The Clear Finance Cloud landing page and the e-Invoicing dashboard - every header, sidebar, and menu control          |
| [Sales Documents](/countries/uae/product-guide/sales-documents)             | Managing outbound invoices, credit notes, and debit notes - filtering, actions, statuses, and troubleshooting         |
| [Purchase Documents](/countries/uae/product-guide/purchase-documents)       | Managing inbound documents from suppliers, and self-billed invoices you raise on their behalf                         |
| [Importing Documents](/countries/uae/product-guide/importing-documents)     | Bulk upload via the Import UI, Import History, and a high-level look at API/SFTP integration                          |
| [Reports](/countries/uae/product-guide/reports)                             | The MIS Dashboard - status and daywise breakdowns, and the per-business overview table                                |
| [Settings](/countries/uae/product-guide/settings)                           | Roles, API credentials, print format, business settings, user access, workspace, email configuration, and API clients |
| [Support Desk](/countries/uae/product-guide/support-desk)                   | Raising and tracking support tickets without leaving the product                                                      |

## Onboarding entry points

Onboarding into ClearTax UAE can also start on the EmaraTax portal instead of on ClearTax - see [End User Onboarding](/countries/uae/end-user-onboarding/overview) for both entry-point flows and their error scenarios in detail. The [Onboarding](/countries/uae/product-guide/onboarding) section in this guide documents the ClearTax-first flow as part of the full product walkthrough.\
