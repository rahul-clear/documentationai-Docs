## API Documentation

REST endpoints are available for integrating with your ERP or accounting system - sending invoices, checking status, querying documents, performing lifecycle actions, and uploading e-reporting transactions. Data can also be ingested via direct upload on the web platform, or SFTP with standard Excel/CSV files.
